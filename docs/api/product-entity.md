# Product Entity

- **Feature:** Product Catalog
- **Entity:** Product
- **Persistence:** N/A, in-memory storage

## Description

The Product entity represents an item available in the product catalog. It is used by the Express API, the Ionic React application, and the Kotlin exercise.

## Structure

Product
- id: number
- name: string
- price: number
- category: string
- stock: number

## Fields

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | number | Yes | Unique incremental identifier generated by the server. |
| `name` | string | Yes | Product name. It cannot be empty and has a maximum length of 60 characters. |
| `price` | number | Yes | Product price. It must be greater than 0. |
| `category` | string | Yes | Product category. It must be one of the allowed catalog categories. |
| `stock` | number | Yes | Available quantity. It must be an integer greater than or equal to 0. |

## Allowed categories

- Bebidas
- Snacks
- Aseo
- Hogar

## Example

{
  "id": 1,
  "name": "Agua",
  "price": 3500,
  "category": "Bebidas",
  "stock": 12
}

## Validation rules

The `name` field is required, must be a string, cannot be empty after trimming spaces, and must not contain more than 60 characters.

The `price` field must be numeric and greater than 0.

The `category` field is required and must be exactly one of the following values: `Bebidas`, `Snacks`, `Aseo`, or `Hogar`.

The `stock` field must be an integer greater than or equal to 0.

## Persistence

N/A, almacenamiento en memoria.

The initial products are loaded from `server/data/products.json`. During execution, created and updated products are stored only in server memory. Restarting the Express server restores the initial state.

## Identifier

The `id` is generated by the Express API. New product identifiers are incremental and must not be entered manually by the user.

## Presentation rules

The domain layer converts product data to presentation values with `toProductView`.

The product price is formatted using `formatCOP`.

The stock label follows these rules:

- `Agotado` when `stock` is `0`.
- `Pocas unidades` when `stock` is less than `5`.
- `Disponible` in any other case.

## Relationships

The Product entity does not have relationships with other entities in this practical exam.

## API usage

The Product entity is used by the following endpoints:

GET /api/products

GET /api/products/:id

POST /api/products

PUT /api/products/:id

DELETE /api/products/:id
